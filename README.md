# SessionDock

**Desktop session explorer and workbench for AI coding agents (Claude Code, Codex, Gemini, WorkBuddy, DSH, and more).**

SessionDock is a powerful graphical interface and development tool for exploring, managing, and inspecting AI coding agent sessions. Built with modern web technologies and Rust, it provides a seamless desktop experience for developers working with multi-agent systems and AI companions.

## Key Features

- **Multi-CLI session browsing & management**: Seamlessly navigate and organize sessions across different AI coding CLIs.
- **Unified session search**: Quickly find conversations, code snippets, or commands across your entire session history.
- **Local API reverse proxy & traffic inspection (`sessiondock-proxy`)**: Monitor, intercept, and analyze API traffic between your AI agents and their backends.
- **Monaco editor with git diff & blame**: Review code changes generated by AI with powerful built-in editor features.
- **Desktop companion & AI assistant**: An integrated desktop experience to boost your productivity.
- **In-app auto-updater**: Powered by GitHub Releases, ensuring you always have the latest features and bug fixes.

## Tech Stack

SessionDock is built on a modern, high-performance stack:

- **Tauri 2**: Lightweight, fast, and secure desktop application framework.
- **Vue 3**: Progressive JavaScript framework for building the user interface.
- **TypeScript**: Typed superset of JavaScript for robust frontend development.
- **Rust**: Systems programming language powering the backend for performance and safety.

## Development Setup

To run SessionDock locally, you'll need [Node.js](https://nodejs.org/) and [Rust](https://www.rust-lang.org/) installed.

1. Clone the repository:
   ```bash
   git clone https://github.com/huangy7/sessiondock.git
   cd sessiondock
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
